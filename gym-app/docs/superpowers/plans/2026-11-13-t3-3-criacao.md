# T3.3 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Criar rotinas demonstrativas durante a sessão atual.
**Architecture:** Context React no layout raiz compartilha rotinas com listagem e entrada de treino. Formulário montado apenas enquanto aberto descarta rascunhos ao fechar.
**Tech Stack:** Expo 58, React Native, Expo Router, NativeWind, componentes existentes.
**Spec:** `docs/superpowers/specs/2026-11-13-t3-3-design.md`

## Global Constraints

- Somente T3.3; sem persistência, dependências novas ou execução da T3.6.
- Cores pelos tokens existentes; componentes compartilhados fora de src/app.
- Rodar lint e typecheck; informar limitações da verificação nativa.

## Review Focus

- Nome ou exercício apenas com espaços não pode gerar rotina incompleta.
- Fechar por botão, backdrop ou voltar deve descartar o rascunho.
- Navegar para treino e Início deve preservar a lista durante a sessão.
- Conteúdo longo e viewport estreito devem permitir alcançar campos e salvar.
- Recarregar deve remover rotinas criadas, sem alterar dados demonstrativos.

### Task 1: Integrar criação, estado de sessão e rota

**Files:** criar `src/contexts/workouts.tsx`, `src/components/create-workout.tsx`;
alterar `src/app/_layout.tsx`, `src/app/workout/[id].tsx`, `src/screens/workouts.tsx`.
**Interfaces:** `useWorkouts()` retorna `workouts: Workout[]`, `addWorkout(workout: Workout): void`;
`CreateWorkout({onClose, onCreate})` emite `Workout` válido; defaults 3, 10–12,
foco `${count} exercícios`, duração count * 10.

- [x] Verificar no navegador que o botão Criar treino está ausente antes da mudança.
- [x] Implementar provider, formulário e conexões; IDs únicos dentro da sessão.
- [x] Validar campos vazios/espaços, adicionar por botão/Enter, cancelar/reabrir,
  salvar/iniciar/voltar, navegar entre telas, reiniciar, nomes longos e temas no navegador.
- [x] Executar `node --test scripts/*.test.cjs`, `npm run lint`, `npx tsc --noEmit`.
- [x] Revisar diff e registrar resultados, sem push ou merge.

## Resultado

Implementado na branch `feat/figma-t3-3-criacao`. Roteiro de navegador mantido em
`scripts/create-workout.browser.cjs`; testes Node existentes, lint e typecheck executados.
Revisão independente sem achados acionáveis. Commit e abertura de PR autorizados
na conversa após a entrega da implementação; merge permanece fora do escopo.

Verificação web: validação de espaços, campos incompletos, cancelamento com descarte,
inclusão por botão e Enter, exercícios duplicados, salvar, iniciar rotina criada,
retornar e navegar via Início sem perder dados. Conteúdo com 16 exercícios e nomes
longos em 320, 390, 720 e 1280 px; temas claro/escuro e reinicialização sem persistência.

Limitação: teclado virtual, botão voltar Android e apresentação iOS/Android não
foram verificados em dispositivo ou emulador. Mantido BottomSheet compartilhado com
KeyboardAvoidingView, rolagem e safe areas existentes.
